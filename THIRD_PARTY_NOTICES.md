# Third-Party Notices

This repository contains code (under MIT) plus data files derived from external datasets. The datasets retain their original licenses.

Each entry in `data/direction_*_candidates.json` and `data/generated_queries*.json` carries a `tenant` field that identifies the source dataset, so attribution can be tracked per-record:

- `tenant ∈ {finance, it, manufacturing, public, retail}` → derived from Allganize/RAG-Evaluation-Dataset-JA (MIT)
- `tenant == "jagov_general"` → derived from sbintuitions/JMTEB JaGovFaqs-22k (CC-BY-4.0)

## Datasets

### Allganize/RAG-Evaluation-Dataset-JA

- **Source**: https://huggingface.co/datasets/allganize/RAG-Evaluation-Dataset-JA
- **License**: MIT
- **Attribution**: Allganize, Inc. — RAG-Evaluation-Dataset-JA
- **What is included in this repo**: `data/documents.csv` (PDF URL / filename / domain metadata only)
- **What is NOT included**: The PDF files themselves and the page-level chunk file (`pdfs/`, `chunks.jsonl`). These are excluded via `.gitignore` because the original PDFs are owned by their respective publishers and cannot be redistributed here. They are regenerated by `scripts/01_prepare/fetch_and_parse_pdfs.py`.
- **Modifications made by this repo**:
  - From the original Allganize dataset, we downloaded the PDFs, ran them through `pdfplumber` for page-level text extraction, and produced page-level chunks (regenerable, not committed).
  - From those chunks, we extracted `chunk_text` excerpts that contain candidate IDF-distortion terms, plus minimal metadata, into `data/direction_*_candidates.json`.
  - We synthesized natural-language queries with `gpt-4o-mini` from those excerpts; these are stored in `data/generated_queries*.json`.

### sbintuitions/JMTEB — JaGovFaqs-22k

- **Source**: https://huggingface.co/datasets/sbintuitions/JMTEB (subset: `jagovfaqs_22k`)
- **License**: [CC-BY-4.0](https://creativecommons.org/licenses/by/4.0/) (per the JMTEB dataset card)
- **Attribution**: SB Intuitions — JMTEB, JaGovFaqs-22k. FAQs are extracted from the websites of Japanese government bureaus.
- **What is included in this repo**: `data/direction_a_candidates.json` and `data/direction_b_candidates.json` contain `chunk_text` excerpts from JaGovFaqs entries (where `tenant == "jagov_general"`) that meet the candidate-term selection criteria. These derivative excerpts remain under CC-BY-4.0 even though the surrounding repository code is MIT.
- **What is NOT included**: The full chunk file (`jagov_chunks.jsonl`) is excluded via `.gitignore` to keep the repo small. It is regenerated by `scripts/01_prepare/fetch_jagovfaqs.py`.
- **Modifications made by this repo** (per CC-BY-4.0 §3.a.1.B):
  - From the full JaGovFaqs-22k corpus, we selected a subset of chunks that contain candidate IDF-distortion terms (criteria are documented in `scripts/01_prepare/select_direction_*_terms.py`). Only the `chunk_text` excerpt and minimal metadata (no full FAQ context) is included.
  - We synthesized natural-language queries with `gpt-4o-mini` from those excerpts; these are stored in `data/generated_queries*.json`. These queries are LLM-generated derivative works, not verbatim FAQ content.

## Derivative Files

### `data/generated_queries.json`, `data/generated_queries_dir_b.json`

- LLM-generated (gpt-4o-mini) "support-desk-style" queries, synthesized from chunk_text excerpts as prompts.
- These are derivative works of the underlying source data. Licenses are inherited per-record according to the `tenant` field:
  - `tenant ∈ {finance, it, manufacturing, public, retail}` → MIT (derivative of Allganize)
  - `tenant == "jagov_general"` → CC-BY-4.0 (derivative of JaGovFaqs); attribute SB Intuitions / JMTEB / JaGovFaqs

### `data/direction_a_candidates.json`, `data/direction_b_candidates.json`

- Candidate-term selections, each with a representative `chunk_text` excerpt and the source `tenant`.
- Same per-tenant licensing as above.
