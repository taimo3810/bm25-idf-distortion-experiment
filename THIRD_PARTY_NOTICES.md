## Datasets

### Allganize/RAG-Evaluation-Dataset-JA

- **Source**: https://huggingface.co/datasets/allganize/RAG-Evaluation-Dataset-JA
- **License**: MIT
- **What is included in this repo**: `data/documents.csv` (PDF URL / filename / domain metadata only)

These are excluded via `.gitignore` because the original PDFs are owned by their respective publishers and cannot be redistributed here. They are regenerated by `scripts/01_prepare/fetch_and_parse_pdfs.py`.

- **Source**: https://huggingface.co/datasets/sbintuitions/JMTEB (subset: `jagovfaqs_22k`)
- **License**: CC-BY-4.0 (per the JMTEB dataset card)
- **Attribution**: "JaGovFaqs-22k" is part of JMTEB, a Japanese MTEB benchmark by SB Intuitions. FAQs are extracted from the websites of Japanese government bureaus.
- **What is included in this repo**: `data/direction_a_candidates.json` and `data/direction_b_candidates.json` contain `chunk_text` excerpts from JaGovFaqs that meet the candidate-term selection criteria. These derivative excerpts are redistributed under CC-BY-4.0.
- **What is NOT included**: The full chunk file (`jagov_chunks.jsonl`) is excluded via `.gitignore` to keep the repo small. It is regenerated by `scripts/01_prepare/fetch_jagovfaqs.py`.

## Derivative Files

### `data/generated_queries.json`, `data/generated_queries_dir_b.json`

- Queries synthesized by `gpt-4o-mini` (OpenAI API) given chunk_text excerpts as prompts.
- These derivatives carry the licenses of the underlying source data:
  - Queries derived from Allganize chunks → MIT
  - Queries derived from JaGovFaqs chunks → CC-BY-4.0 (attribute SB Intuitions / JMTEB / JaGovFaqs)
- Each entry in the JSON includes a `tenant` field (`finance`/`it`/`manufacturing`/`public`/`retail` for Allganize; `jagov_general` for JaGovFaqs) so attribution can be tracked.

### `data/direction_a_candidates.json`, `data/direction_b_candidates.json`

- Candidate-term selections plus a single representative `chunk_text` snippet per term, identifying the source `tenant`.
- Same per-tenant licensing as above (MIT for Allganize tenants, CC-BY-4.0 for JaGovFaqs).
